# ScatterAndGlow

- **Pensieve source / credit:** Dror Bar-Natan, [Projects/ScatterAndGlow](https://drorbn.net/AcademicPensieve/Projects/ScatterAndGlow/)

## What this is

A collection of working pages and Mathematica notebooks with titles such as “Scatter And Glow,” “Implementation Notes for S&G,” “Hair Formulas,” “Commutators Commute,” “Reducing Exp(…),” and “Degrees in BCH.” Several files explicitly compute Baker–Campbell–Hausdorff expressions modulo families of commutator relations.

## What is being worked out

The safest description is an algebraic/computational exploration of BCH expansions and special commutator structures. The folder name alone does not expose enough context to identify the eventual topological application, so this note avoids assigning one.
