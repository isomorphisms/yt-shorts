# JacobiDiagrams

- **Pensieve source / credit:** Dror Bar-Natan, [Projects/JacobiDiagrams](https://drorbn.net/AcademicPensieve/Projects/JacobiDiagrams/)
- **Related work:** Bar-Natan's older computations on Vassiliev invariants

## What this is

An archival source-code collection, mostly from 1994–1998, for computations with Jacobi diagrams and Vassiliev/finite-type invariants. It includes C and Mathematica code, IHX-relation calculations, basis-generation tools, and auxiliary programs such as nauty/yam-suff integrations.

The Pensieve warns that the old code may need adjustment and does not provide a modern manual.

## What it demonstrates

This is useful as computational history: large diagram spaces and their relations were already being attacked by explicit enumeration, graph isomorphism, and linear algebra decades ago. It should be treated as an archive, not a current turnkey package.
