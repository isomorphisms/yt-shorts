- **Related project:** [glneps](glneps.md)

## What this is

SolvablePBW studies explicit Poincaré–Birkhoff–Witt generating functions for broad classes of solvable and ε-solvable Lie algebras. The active notebooks build multiplication tensors and related formulas rather than treating PBW only as an existence theorem.

One strand develops the multiplication tensor for glₙ,ᵋ using a nilpotent/tangent formalism; another studies examples that test how general structural decompositions really are. The folder also contains experiments with other solvable algebras and a QU multiplication tensor.

## What is being worked out

The project is trying to turn PBW reordering from an abstract statement into a practical symbolic calculus that scales across an entire class of algebras. It is closely connected to the computational Lie-algebra infrastructure used elsewhere in the Pensieve.
