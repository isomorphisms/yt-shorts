# FreeLie

- **Pensieve source / credit:** Dror Bar-Natan, [Projects/FreeLie](https://drorbn.net/AcademicPensieve/Projects/FreeLie/)

## What this is

This project page is mainly an archival pointer. Bar-Natan notes that the work dissolved into monthly folders and into other locations, including the Yusuke Kuno People folder and WKO4-related material.

## How to use the source

Do not treat `Projects/FreeLie` as a self-contained finished project. Its value is navigational: it identifies a research thread around free-Lie computations that migrated elsewhere in the Pensieve. Any substantive description should cite the destination notebook or paper actually used.
