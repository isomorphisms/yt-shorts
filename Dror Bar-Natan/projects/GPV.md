# GPV

- **Pensieve source / credit:** Dror Bar-Natan, [Projects/GPV](https://drorbn.net/AcademicPensieve/Projects/GPV/)
- **Related collaborator:** Peter Lee

## What this is

A 2009–2015 computational archive around the GPV algorithm and the Polyak algebra for finite-type invariants of virtual knots. The notebooks include “Cut and Cap,” degree-by-degree Polyak-algebra computations, and rank calculations through degree 5.

One branch adds an HTC relation and extends the calculation to tangles in joint work with **Peter Lee**.

## What is being worked out

The project converts Gauss/arrow-diagram relations into finite linear computations. The visible goal is not simply to state the Polyak algebra but to implement the quotient, compute dimensions/ranks, and test algorithmic operations on diagrams.
