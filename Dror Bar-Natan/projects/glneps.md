# glneps — glₙᵋ

- **Pensieve source / credit:** Dror Bar-Natan, [Projects/glneps](https://drorbn.net/AcademicPensieve/Projects/glneps/)
- **Related project:** [SolvablePBW](SolvablePBW.md)

## What this is

This 2026 project contains notebooks described as a full implementation of an ε-deformed glₙ, along with LU decomposition, base-change/testing work, rotation-number calculations, and two-variable polynomial plotting.

## What is being worked out

The folder looks like the concrete implementation layer underneath parts of SolvablePBW: define the deformed algebra explicitly, make its multiplication/reordering computational, and test the resulting formulas in low-dimensional and visualizable cases.

A project image named after Schaveling's thesis appears in the folder; that filename is a citation clue, not sufficient evidence to reuse the image or to infer its exact provenance without checking the source file.
