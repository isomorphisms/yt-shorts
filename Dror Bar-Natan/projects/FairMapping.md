# FairMapping

- **Pensieve source / credit:** Dror Bar-Natan, [Projects/FairMapping](https://drorbn.net/AcademicPensieve/Projects/FairMapping/)

## What this is

A 2010–2011 computational cartography project using Mathematica to transform maps in response to population density. Files include population-density maps, “FairParcellation,” and early map experiments.

## Citation trail

The page links **Quentin Mérigot** and work on multiscale optimal transport, along with examples of social/economic world mapping and the PNAS literature on diffusion-based density-equalizing maps.

## What is being worked out

The mathematical question is how to deform geographic area so that the map represents a non-geographic quantity—especially population—more faithfully while remaining recognizable. It sits closer to computational geometry/optimal transport than to Bar-Natan's knot-theory projects.

Any map image needs its own provenance check before reuse; the Pensieve page mixes generated material with external references.
