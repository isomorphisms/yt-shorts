# MetaMonoids

- **Pensieve source / credit:** Dror Bar-Natan, [Projects/MetaMonoids](https://drorbn.net/AcademicPensieve/Projects/MetaMonoids/)
- **Linked paper:** [arXiv:1302.5689](https://arxiv.org/abs/1302.5689)

## What this is

A construction page for meta-monoid / β-calculus work. The folder contains executable examples and many explicit diagram assets: Reidemeister R1/R2/R3, β-calculus presentations, Borromean-link and multivariable-Alexander examples, and tests over knots and links.

## What is being worked out

The project builds a compositional algebraic language for tangle/knot calculations. A good way to read the assets is as unit tests for topology: define local algebraic rules, compose them, and verify that Reidemeister-equivalent diagrams give compatible results.
