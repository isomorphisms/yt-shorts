# KnotTheory

- **Pensieve source / credit:** Dror Bar-Natan, [Projects/KnotTheory](https://drorbn.net/AcademicPensieve/Projects/KnotTheory/)

## What this is

This folder is largely infrastructure for Bar-Natan's Mathematica **KnotTheory`** package rather than a single research theorem. A build script assembles package modules into `KnotTheory/init.m` and distributable archives; other material records bug reports and links to related tools such as KnotJob.

## What it demonstrates

The useful story here is computational plumbing: a public knot-theory research program depends on maintained data structures, invariant implementations, packaging, and regression fixes. Treat individual package claims according to the module/version actually used.
