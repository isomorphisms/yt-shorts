# 3H — 3-Heisenberg formalism for Θ

- **Pensieve source / credit:** Dror Bar-Natan, [Projects/3H](https://drorbn.net/AcademicPensieve/Projects/3H/)
- **Related projects:** [Theta](Theta.md), [BabyDoPeGDO](BabyDoPeGDO.md)

## What this is

The folder is an attempt to formulate the Θ invariant inside a three-Heisenberg computational formalism. Its engine is explicitly connected to the earlier BabyDoPeGDO work, and formulas are carried over and modified from the Bonn-2505 talk material.

The project page also warns, in effect, that conventions changed during development: some files predate the later switch in ordering conventions. That is useful provenance when reading old formulas.

## What is being worked out

The main target is not a new isolated knot picture but a computational language for the algebra behind Θ. The notebooks try to make the invariant's higher-order structure calculable in a controlled Heisenberg-style algebra rather than leaving it as an opaque symbolic expansion.
