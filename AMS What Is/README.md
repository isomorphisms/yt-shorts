# AMS Notices: “What Is…?”

Source-research folder for the **“What Is…?”** articles in the *Notices of the American Mathematical Society*, plus a few closely related *Notices* expository articles named in the initial pass.

This is research substrate for YouTube Shorts, not a collection of finished scripts and not a mirror of copyrighted PDFs. Preserve author credit and link the AMS source whenever a later Short uses one of these notes.

## Main indexes

- Armin Straub’s maintained index: https://arminstraub.com/math/what-is-column
- AMS “What Is” collection: https://www.ams.org/cgi-bin/notices/nxgnotices.pl?cnt=whatis&fm=gen
- *Notices of the AMS*: https://www.ams.org/notices

Straub’s index is unusually useful because it puts the whole column in one chronological list and links each entry back to the AMS. The snapshot inspected for this folder runs from Oleg Viro’s **“What is…an amoeba?”** (September 2002) through the February 2026 entries.

## Keep the categories straight

The actual **“What Is…?”** column consists of short explanations of a focused mathematical object or topic. The Greene, Pinzón-Caicedo/Ruberman, and Grigsby items below are broader *Notices* expository features, not entries in the “What Is…?” column. They are kept here because they were explicitly named in the same research request and are exactly the sort of source material this Shorts repository is collecting.

## Working rule for later Shorts

For each source, keep the mathematical unit small: one definition, one example, one picture, one surprising equivalence, or one question. Do not try to summarize an entire field in a 20-second clip. Credit the article author(s) on screen or in the accompanying text and link the original AMS article.
