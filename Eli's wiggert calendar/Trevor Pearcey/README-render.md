# Pearcey animation draft

The current draft animates the symmetric cutoff

\[
P_T(x,y)=\int_{-T}^{T} e^{i(t^4+y t^2+x t)}\,dt
\]

and colors the resulting complex field with the pinned Wegert coloring core.

On-screen mathematical notation should use true subscripts and superscripts where practical: `Pₜ`/`P_T` in rendered math, `t⁴`, `t²`, `x²`, `y³`, and the cusp `27x² + 8y³ = 0`. Avoid ASCII caret notation in visible titles or annotations.

The committed MP4 is a visual draft. The numerical production version can later replace the real-axis truncated quadrature with contour deformation / steepest descent without changing the visual ownership boundary.
